## 🚀 Local Development

This is a static site — no build step or dependencies required.

```bash
git clone https://github.com/RoohulAmin-dev/roohulamin-dev.github.io.git
cd roohulamin-dev.github.io
```

Then simply open `index.html` in your browser, or serve it locally:

```bash
# using Python
python3 -m http.server 8000

# or using the VS Code "Live Server" extension
```

Visit **[http://localhost:8000](http://localhost:8000)**.
